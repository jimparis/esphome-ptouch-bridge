# ESPHome P-touch Bridge

Use this installer to load the pre-built firmware onto an original ESP32 over
USB. After installation, configure Wi-Fi and adopt the device in ESPHome Device
Builder.

<esp-web-install-button manifest="firmware/ptouch_bridge.manifest.json">

for configuration and source code.
